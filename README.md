# ShareCapsule Prepare

**Prepare for the goal, not just the syllabus.**

Canonical product URL: **https://prepare.sharecapsule.app**

ShareCapsule Prepare is an adaptive preparation platform that starts with a learner's target and deadline, measures where they are today, identifies the highest-value gaps, and continuously adjusts a preparation plan until the target date.

## Initial use cases

### 1. Academic / exam preparation
A learner provides:
- grade level
- exam, subject, or specialization target
- target date
- topics/syllabus
- available study time
- optional study guides, notes, or previous scores

Prepare then builds a competency map, runs a diagnostic, identifies gaps, curates learning resources, schedules practice, and reassesses readiness.

### 2. Company / role interview preparation
A candidate provides:
- company
- target role and level
- interview date
- job description
- experience and skills
- optional resume / portfolio / GitHub information

Prepare builds a target competency model, uses public and reputable interview-preparation evidence to identify likely skill areas and representative question patterns, runs a diagnostic, and creates a deadline-aware preparation plan. The product must not claim access to confidential or leaked interview questions.

## Core loop

`Goal -> Deadline -> Diagnostic -> Gap Analysis -> Plan -> Learn -> Practice -> Reassess -> Readiness`

## MVP principles

1. Diagnose before recommending content.
2. Track skills and prerequisites, not just topic completion.
3. Spend more time on important gaps than on already-mastered material.
4. Adapt the plan to the time remaining.
5. Prefer authoritative, attributable learning resources.
6. Keep readiness as an estimate of preparation, not a guarantee of exam/interview success.

## MVP phases

- **Phase 1:** Goal intake + diagnostic question generation + scoring
- **Phase 2:** Skill graph + gap analysis + deadline-aware plan
- **Phase 3:** Curated videos/documents + micro-assessments
- **Phase 4:** Mock exams/interviews + readiness dashboard
- **Phase 5:** reminders, progress automation, and richer personalization
